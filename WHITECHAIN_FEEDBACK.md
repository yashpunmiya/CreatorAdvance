# Whitechain feedback

CreatorAdvance targets Whitechain Sepolia's Tokenize track. We verified the public RPC chain ID (`1874`), organizer USDT contract bytecode, symbol, and six-decimal precision. The chain and token configuration was straightforward to confirm from the event page and network RPC.

We deployed CreatorAdvance at [`0x598c4fb5aeb0f2965782a73c40972ecb8056e7fa`](https://explorer.testnet.whitechain.io/address/0x598c4fb5aeb0f2965782a73c40972ecb8056e7fa) and completed an issuance-to-funding flow with separate brand, creator, and investor wallets. The 5 USDT invoice was [issued](https://explorer.testnet.whitechain.io/tx/0x757eea0af8abba94e6886140e87dbf0bd549d4a001325f9d6de18eec5afe7bbc) and [approved by the brand](https://explorer.testnet.whitechain.io/tx/0x15cefb3be4b1fae9fcd42ede73df86f1b96f60880db5b3d901b65866c7164647). The investor escrowed 4.8 USDT [here](https://explorer.testnet.whitechain.io/tx/0xe2f9e13345f0303bb11d18335280f3fca33a819a7ecbf44e23ffeb9b0975663c). The successful `acceptOffer` transaction [paid 4.8 organizer USDT to the creator and minted the CAR claim to the investor](https://explorer.testnet.whitechain.io/tx/0xd5f2fec51f9f480f4d15f2e8b90126df15c29fa87b8f5650c973e5b118032d7d). The payout token is the organizer's exact six-decimal USDT contract, `0xcedfB56113143d55b2358b8CFbB0dEB5Ad2f55a7`.

The successful live settlement confirms that organizer USDT can be used in the main financing flow. The explorer API still reports `is_verified: false` for the deployed contract, so source verification remains outstanding. Repayment and default recovery have not been exercised live. The public documentation could make the organizer-USDT funding path easier to locate, and a clearer guide to explorer source verification would help teams publish matching source and constructor settings. The repository is being published for this track.
