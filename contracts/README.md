# CreatorAdvance contracts

Foundry project for the Whitechain Sepolia receivable financing lifecycle. Uses Solidity 0.8.30, Prague EVM target, and OpenZeppelin Contracts 5.6.1. Never deploy this test project to mainnet.

Run in WSL from `contracts/` with `~/.foundry/bin/forge build` and `~/.foundry/bin/forge test -vvv`.
